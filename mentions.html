Mentions et licences

Le code de ce site est ouvert. L’identité de France Travail ne l’est pas : voici ce que cela implique pour réutiliser le projet proprement.

La licence MIT ne couvre pas l’identité de France Travail

Marques, logotypes, typographie Marianne et éléments d’identité visuelle restent soumis à leurs propres conditions, même publiés dans un dépôt public.

Code source

Sauf mention contraire, le code source de ce site est mis à disposition sous licence MIT.

Éléments exclus de la licence MIT

La licence du code ne couvre pas les marques, les noms, les logotypes et les éléments d’identité visuelle de France Travail ou de la République française. Elle ne couvre pas non plus la typographie Marianne, soumise à ses propres conditions d’utilisation, ni les identités propres aux projets référencés.

Leur présence dans un dépôt public ne leur confère pas une licence open source.

Vous souhaitez forker ce site ?

  1. Remplacez les logotypes et éléments de marque officiels.
  2. Remplacez Marianne par une police dont la licence autorise votre usage.
  3. Adoptez une identité visuelle qui ne puisse pas être confondue avec un service officiel.
  4. Vérifiez séparément la licence de chaque projet que vous réutilisez.

Design System France Travail

Le site utilise les composants web, les styles et les icônes du Design System France Travail (nouvel onglet), dont il embarque une copie dans le dossier vendor/dsft/. Le code publié du Design System est sous licence MIT ; ses éléments de marque et ressources soumis à des conditions spécifiques restent exclus.
